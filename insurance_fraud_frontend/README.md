# insurance_fraud_frontend

React (CRA) frontend for the insurance claim fraud detection platform.

## Run (port 3000)

```bash
npm install
npm start
```

## Environment

This project uses CRA env variables (must start with `REACT_APP_`).

- `REACT_APP_API_BASE` (recommended): backend base URL, e.g. `http://localhost:3001`
- `REACT_APP_BACKEND_URL`: fallback base URL
- `REACT_APP_SUPABASE_URL`, `REACT_APP_SUPABASE_KEY`: optional (for future auth)

The repository already contains a `.env` file in this folder in the workspace environment.
